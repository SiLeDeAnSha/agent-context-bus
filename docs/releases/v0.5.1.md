v0.5.1 · P1 Reliability Fixes, Late-Device Auto-Resummarize & Cross-Platform Sanitization

### Highlights / 核心修复

- **Late-Device Auto-Resummarize & Multi-Slot Mac Catchup (`server/app.py`, `summarizer.py`, `collect.py`, `deploy/setup_mac_collector.sh`)**
  - `POST /api/v1/ingest/raw` now applies server-side redaction and schedules a 120s debounced auto-resummarize (`SUMMARIZE_PUSH_DEBOUNCE_SEC`, serialized via lock) whenever a late device pushes a completed workday's raw shard; still-active workdays are never compacted prematurely.
  - `summarizer.find_unsummarized_raw_days()` now compares covered `machines` and `latest_uploaded_at` against existing daily summaries so late-arriving machines are always picked up on scheduled runs too.
  - `collect.py --skip-pushed` records completed pushed workdays per machine for idempotent multi-slot macOS `launchd` catchup schedules (`08:55` primary + `10:30 / 14:00 / 19:00` wake-from-sleep fallbacks).
- **Pre-Migration Legacy Archive Preservation (`multi_machine.py`)**
  - `save_machine_raw()` now persists pre-migration single-machine raw files as dedicated `machines/<legacy>/raw/` shards before rebuilding the merged archive, preventing historical records from disappearing on the second machine's upload.
- **End-to-End `live_notes` Retention Across Merge, Summarization & Search (`multi_machine.py`, `summarizer.py`, `search_fts.py`, `query_memory.py`)**
  - Preserves and deduplicates `live_notes` (and tags `claude` sessions) across multi-machine raw merges, feeds `live_notes` and hub live notes into both LLM and fallback summarizers, and indexes archived `--note` entries in both FTS5 and exact regular queries so notes remain retrievable after compaction.
- **Hardened External Report Path Sanitization (`export_report.py`)**
  - Rewrote `sanitize_text()` to strip full Windows drive paths (`C:\Users\...`), POSIX user paths containing spaces (`/Users/.../Application Support/...`), and credentials via `redact.redact_text()`.
- **Complete Python 3.9 Compatibility (`export_report.py`, `onboarding.py`, `prepare_gsheets.py`)**
  - Completed `from __future__ import annotations` and optional `openpyxl` imports across all top-level CLI modules so default macOS Python 3.9 runs cleanly out of the box.
