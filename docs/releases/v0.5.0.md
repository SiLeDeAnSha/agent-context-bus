v0.5.0 · FTS5 Search, Decisions Supersede Chain, Credential Redaction & Web Dashboard

### Highlights / 核心更新

- **Zero-Dependency SQLite FTS5 Search (`search_fts.py`)**
  - Derived `data/search_index.db` (`unicode61` + `trigram` + short-term fallback + BM25 + RRF + recency/decision boosts) on pure Python stdlib with zero pip dependencies.
  - Covers full historical daily summaries, live WAL, long-term decisions, and incremental 30-day raw session turns; `--exact` fallback works across both local and remote modes; reserves `VectorProvider` seam for optional future embeddings.
- **Decisions & Pitfalls Ledger with Supersede Chain (`decisions.py`)**
  - Dedicated `data/decisions.json` store supporting `project` / `global` scopes and `decision` / `constraint` / `pitfall` kinds.
  - Full CLI & API lifecycle (`--decision`, `--global-decision`, `--decisions`, `--supersede`, `--forget-decision`) with cycle detection, duplicate-supersede guard, soft-delete tombstones, and nightly candidate ingestion.
- **Pre-Persistence Credential Redaction (`redact.py`)**
  - Automatically redacts PEM private keys, JWT/Bearer tokens, OpenAI/Anthropic/GitHub/AWS/Google/Slack/HF keys, URL credentials, Cookies, and secret assignments before writing live WAL, `raw_*.json`, LLM payloads, or NAS shards, while preserving Git SHAs, file paths, and placeholders.
- **High-Density 0-Token Live WAL & Multi-Machine Sync (`live_memory.py`, `multi_machine.py`)**
  - 64 KB tail seek extracts `last_user_prompt`, `last_assistant_summary`, and `touched_files` across Antigravity / Codex / Claude Code / WorkBuddy with zero extra LLM tokens.
  - Non-blocking 30s-debounced `--push-remote` pushes per-machine live shards to the NAS hub (`/api/v1/live/push`) and merges them into `/api/v1/live`, `/api/v1/status`, and `MEMORY_INDEX.md`.
- **8 Streamable-HTTP MCP Tools & Swiss Minimalist Web Dashboard (`server/app.py`, `server/ui.html`)**
  - Expanded `/mcp` from 5 read-only tools to 8 tools by adding `write_token`-guarded `memory_add_note`, `memory_register_path`, and `memory_add_decision`.
  - Zero-build Web UI at `GET /ui` (`sessionStorage` Bearer auth, `nosniff` / `no-referrer` / CSP headers) with Overview & Live WAL, FTS5 Search, Projects & Paths copy, and Decisions management.
- **Modular Adapters & Diagnostics (`adapters/`, `doctor.py`)**
  - Split client collectors into `adapters/{antigravity,codex,claude,workbuddy}.py`.
  - Added `--doctor` / `--fix` for Python/SQLite FTS5 checks, 4-client rule & hook verification (including `~/.gemini/config/hooks.json`), data integrity checks, stale temp cleanup, and multi-endpoint NAS probing.
